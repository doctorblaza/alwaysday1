# 入职第一天

> M科技职场升级文字冒险游戏 — 网页版（v7）

你即将进入 M 科技公司。你的每一个选择都会影响你的命运——

- 📊 **影响力 (Impact)** — 你在公司的影响力和可见度
- 😰 **压力** — 你承受的心理压力
- ⚖️ **底线** — 你的道德底线和原则
- 📰 **信息量** — 你掌握的内部信息
- 🤝 **关系网** — 你的人脉广度

还有隐藏数值：与 Kevin、老陈、赵总、周工的关系，吹哨人伏笔，自我牺牲标记——它们不会直接显示，但会在关键节点改变剧情走向。

八个结局全部可达：登顶、创业、吹哨人、随波者、出局、觉醒、体面离场，以及隐藏结局轮回。

## 画面

v7 港漫风视觉（全部彩色赛璐璐平涂，内嵌单文件，无外部资源）：

- 11 张人物立绘：赵总、安南、Kevin、老陈、方姐、小林、Buddy、深海鱼、老周、周工、食堂阿姨
- 16 张场景背景：梦境、园区、大堂、走廊、深夜办公室、会议室、食堂、茶水间、电梯、楼梯间、健身房、地铁站、停车场、天台、家、水族馆
- 8 张结局 CG：每个结局一张专属 CG

## 如何游玩

访问 GitHub Pages：https://doctorblaza.github.io/alwaysday1/

或本地直接用浏览器打开 `index.html`。手机竖屏（390×844）优先。

## 技术栈

- 纯 HTML/CSS/JavaScript，单文件，无任何依赖
- 自动存档 / 继续 / 重新开始，结局图鉴与 New Game+ 存于 localStorage
- 回归测试：`node tests/verify-endings.js`（八个结局真实引擎重放，8/8 通过）
