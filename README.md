# 入职第一天

> M科技职场升级 AVG 视觉小说 — 网页版（v8）

你即将进入 M 科技公司。你的每一个选择都会影响你的命运——

- 📊 **影响力 (Impact)** — 你在公司的影响力和可见度
- 😰 **压力** — 你承受的心理压力
- ⚖️ **底线** — 你的道德底线和原则
- 📰 **信息量** — 你掌握的内部信息
- 🤝 **关系网** — 你的人脉广度

还有隐藏数值：与 Kevin、老陈、赵总、周工的关系，吹哨人伏笔，自我牺牲标记——它们不会直接显示，但会在关键节点改变剧情走向。

八个结局全部可达：登顶、创业、吹哨人、随波者、出局、觉醒、体面离场，以及隐藏结局轮回。

## 画面

v8 全幅 AVG（对齐《60天》视觉小说形态，手机竖屏优先，桌面同样全幅）：

- 全屏电影式舞台：背景全屏铺满，双层淡入淡出
- 11 张人物立绘（透明底，站在场景上）：赵总、安南、Kevin、老陈、方姐、小林、Buddy、深海鱼、老周、周工、食堂阿姨
  - 左 / 中 / 右站位，说话人高亮、其余压暗
- 底部全宽电影黑渐变对话框（人名 + 打字机）
- 全屏选项浮层、章节卡、结局 CG
- 16 张场景背景：梦境、园区、大堂、走廊、深夜办公室、会议室、食堂、茶水间、电梯、楼梯间、健身房、地铁站、停车场、天台、家、水族馆
- 8 张结局 CG：每个结局一张专属 CG

全部 35 张美术内嵌单文件，无外部资源。

## 如何游玩

访问 GitHub Pages：https://doctorblaza.github.io/alwaysday1/

或本地直接用浏览器打开 `index.html`。手机竖屏（390×844）优先，桌面（1440×900）同样全幅。

点击 / 空格推进剧情。AUTO 默认开启（按字数自动推进，选项处暂停，结局处停住）。

## 技术栈

- 纯 HTML/CSS/JavaScript，单文件，无任何依赖
- 自动存档 / 手动存档（3 槽）/ 读档，结局图鉴与 New Game+（二周目 · 再入职）存于 localStorage
- 回归测试：`node tests/verify-endings.js`（八个结局真实引擎重放，8/8 通过）
