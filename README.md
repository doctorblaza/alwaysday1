# 入职第一天

> 大厂职场生存文字冒险游戏 — 网页版

## 游戏简介

你即将进入 M 科技公司。你的每一个选择都会影响你的命运——

- 📊 **影响力 (Impact)** — 你在公司的影响力和可见度
- 😰 **压力** — 你承受的心理压力
- ⚖️ **底线** — 你的道德底线和原则
- 📰 **信息量** — 你掌握的内部信息
- 🤝 **关系网** — 你的人脉广度

还有隐藏数值：与 Kevin、老陈、赵总、周工的关系，吹哨人伏笔，自我牺牲标记——它们不会直接显示，但会在关键节点改变剧情走向。

两条主线：**高压线（Growth 组）** 与 **技术线（Infra 组）**。八个结局：登顶者、创业者、吹哨人、随波者、出局者、觉醒者、体面离场者，以及隐藏结局 Loop。
