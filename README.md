# 入职第一天

> 大厂职场生存文字冒险游戏 — 网页版（v16）

你即将进入 M 科技公司。你的每一个选择都会影响你的命运——

所有数值（影响力、压力、底线、信息量、关系网、人物关系、隐藏标记）都在幕后结算，界面不再显示。你只需要做选择，然后承担后果。

两条主线：**高压线（Growth 组）** 与 **技术线（Infra 组）**。八个结局全部可达：轮回、吹哨人、登顶、出局、创业、体面离场、觉醒、随波者。

终局只显示结局名称 + 一句点题语（与剧本 v8 同步：第六章不再写完整结局叙事）。

## 画面

港漫硬朗线赛璐璐风：全部人物立绘（赵总、安南、Kevin、老陈、方姐、小林、深海鱼、阿杰等）与 16 张横版 16:9 章节背景（无人物、无可辨认文字），全部内嵌于单文件，无外部资源。

## 玩法

- 点击 / 空格推进剧情；AUTO 自动播放；**快进**一键跳过对话，遇到选项自动停下（不会替你选）
- 章节结算只保留剧情文本，不再显示数值面板
- 结局图鉴：横版卡片布局；打开图鉴时菜单隐藏，点"返回"回到菜单
- 自动存档 / 继续 / 读档，结局图鉴与 New Game+ 存于 localStorage
- 二周目·再入职：与剧本 v8 同步——老陈多看你一眼、食堂阿姨改口、小林组织架构图上的问号、深海鱼帖子多一句，开场梦按上一轮结局变化（轮回 / 觉醒 / 随波者）
